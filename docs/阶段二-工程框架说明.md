## 二、启动方式

### 后端（Jetty 9.4，Servlet 3.1 / javax）

```bash
cd backend
mvn clean jetty:run          # IDEA 的 Terminal 或 Windows cmd 里执行
# 访问：http://localhost:8080/life-manager/
```

> ⚠️ **Git Bash 下 `mvn` 包装脚本会报 `ClassNotFoundException: Launcher`**（路径转换问题）。  
> 解决办法二选一：① 用 cmd / IDEA Terminal；② 直接用 java 启动 launcher：
>
> ```bash
> java -classpath 'D:\software\apache-maven-3.6.3\boot\plexus-classworlds-2.6.0.jar' \
>      -Dclassworlds.conf='D:\software\apache-maven-3.6.3\bin\m2.conf' \
>      -Dmaven.home='D:\software\apache-maven-3.6.3' \
>      org.codehaus.plexus.classworlds.launcher.Launcher jetty:run
> ```

### 前端

```bash
cd frontend
npm install
npm run dev                  # http://localhost:5173（/api 自动代理到后端）
```
